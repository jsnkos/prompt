# awesome-ai-literature-reading

面向研究生和科研人员的 AI 文献阅读 Prompt 与 Agent Skill 模板库，重点用于快速理解论文的研究问题、方法结构、公式逻辑、实验设计、创新性与可借鉴性。

## 为什么做这个项目

在科研阅读中，很多同学并不是不会读论文，而是不知道应该从哪些角度拆解论文。尤其是面对多模态学习、信息瓶颈、变分推断、对比学习、聚类等方向时，单纯总结摘要并不能真正帮助理解论文。

本项目希望提供一套可直接复制使用的文献阅读 Prompt，并进一步整理为 Agent Skill，使 AI 助手能够按照固定流程帮助用户进行深度论文分析。

## Prompt 模板

- 文献精读
- 方法拆解
- 公式解释
- 损失函数分析
- 实验分析
- 创新性判断
- Related Work 借鉴
- Reviewer 视角审视

## Agent Skill

本项目提供一个 paper-reading skill，可用于 Cursor 或 Claude Code 等支持 Agent Skills 的工具中。用户只需要上传论文 PDF 或粘贴论文内容，并说明研究方向，即可触发结构化文献阅读流程。
